# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

Apex-RE is an open-source reverse engineering research toolkit and AI agent skill. If you discover a vulnerability or security flaw in any of the bundled analysis scripts:

1. Do not open a public GitHub issue.
2. Contact the maintainer directly or email realwespcai@gmail.com with a reproduction scenario.
3. You will receive an initial response within 48 hours.

## Intended Purpose & Ethical Research

Apex-RE is designed for legitimate software interoperability, binary forensics, game modding, debugging, educational research, and format reverse engineering. Users are responsible for complying with all applicable local, national, and international laws.
